# Harmony Gates — Voice Leading Complete Asset Pack

This pack is intended to contain the complete *visual primitive layer* needed to build the Voice Leading module without baking runtime behavior into the background.

## Folder order
00 background: environmental plate.
01 controls: button shells, icon buttons, icons, selectors, toggles, slider, chips.
02 navigation: top bar, tabs, section plate.
03 panels: exercise, control, feedback, stats, voicing, keyboard, staff panels.
04 progress bars: progress/mastery/accuracy/level states.
05 status indicators: MIDI and exercise states.
06 voice motion: reusable voice-leading paths, arrows, target/current/history rings.
07 note tokens: note states and keyboard key primitives.
08 feedback: feedback containers for correct/incorrect/partial/neutral/hint.
09 transient surfaces: drawer, bottom sheet, setup/settings/help modals, dropdown.
10 templates: full-screen layout skeletons for landing, practice, voice path and keyboard practice.
11 guides: design grid, safe zone and component sizing.
12 maps: draft screen contract, state matrix and manifest.
13 docs: implementation and Figma assembly guidance.
14 compose_reference: Compose-oriented component/state naming reference.
15 png_exports: raster exports of vector primitives when SVG rasterization is available.

All text labels and runtime values should be supplied by Figma/Compose, not rasterized into the reusable primitive.
