# Exercise policies

Exercise policies land here in Phase 6. Each one defines a root/key pool, chord formula pool,
inversion pool, voicing family, register constraints, assistance profile and answer policy —
the checklist in `docs/spec/21_CONTENT_AUTHORING_GUIDE.md` §4.

Formula references must name an id from `ChordFormulas`; the content validator fails the build
on an unknown one.
