# Asset usage rules
- Background is static environment only.
- SVG shells may be used as Figma references or translated into Compose shapes.
- No exercise answer, chord/voicing name, current note, progress value, MIDI device, score, timer, or feedback message is permanently embedded in an asset.
- State variants exist so Figma can show behavior, but production state is programmatic.
- Final hit regions must follow the final approved visible control geometry.
